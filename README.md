# MSKquestions

A comprehensive question bank and learning platform for musculoskeletal medicine.

This repository contains the front-end code for the MSKquestions application, optimized for deployment on GitHub Pages.

## Local Development

Simply open `index.html` in your browser. No build steps are required for this vanilla stack!

## Features
- Premium, modern glassmorphism UI
- Responsive design tailored for mobile and desktop
- Interactive Quiz modules
